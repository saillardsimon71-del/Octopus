# Identifiants de test

Non applicable : OCTOPUS est ici une application locale Python/SQLite, sans compte utilisateur
ni authentification ajoutée ou modifiée. Aucun identifiant réel n'est nécessaire pour la suite.

de credentials réels aux tests. Les preuves/encaissements de test ne sont pas commerciaux.
